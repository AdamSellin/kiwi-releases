## ✨ Ce que fait Kiwi

| | |
| --- | --- |
| 🔎 **Un grand catalogue** | Titres, artistes, albums, playlists, classements, genres, radios et nouveautés. |
| 🎧 **Les titres en entier** | Lecture en arrière-plan et écran verrouillé, commandes au casque et dans la notification, file d'attente. |
| 📥 **Hors ligne** | Titres, albums et playlists téléchargés avec leurs paroles, jouables sans réseau. |
| 💚 **Votre bibliothèque** | Titres aimés, playlists perso, historique, « Reprendre l'écoute », Flow et mixes découverte. |
| 🎤 **Paroles et égaliseur** | Paroles synchronisées, égaliseur avec préréglages, qualité audio réglable. |
| 🔒 **Rien ne sort du téléphone** | Ni compte, ni serveur, ni pub, ni pistage. Sauvegarde de la bibliothèque dans un fichier. |

## 📲 Installer

1. **Téléchargez** l'APK depuis le téléphone : le bouton ci-dessus convient à presque tous les téléphones.
2. **Ouvrez le fichier** depuis la notification de téléchargement ou l'app Fichiers.
3. **Autorisez cette source**, une seule fois : Android le demande pour les applis qui ne viennent pas du Play Store (« Installer des applis inconnues »).
4. **Installez.** Kiwi apparaît avec vos autres applis.

<details>
<summary><b>Quel fichier choisir ?</b></summary>
<br>

| Fichier | Pour |
| --- | --- |
| `app-arm64-v8a-release.apk` | Presque tous les téléphones (conseillé) |
| `app-armeabi-v7a-release.apk` | Téléphones anciens ou d'entrée de gamme (32 bits) |
| `app-x86_64-release.apk` | Émulateurs, quelques tablettes et Chromebook |
| `app-release.apk` | Universel : marche partout, plus lourd |

Chaque version publie aussi `SHA256SUMS.txt`, les sommes de contrôle de ses fichiers.
</details>
